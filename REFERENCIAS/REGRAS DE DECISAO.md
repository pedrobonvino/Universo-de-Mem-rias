
Este arquivo existe para me ajudar a escolher com mais clareza onde cada coisa mora no meu Universo de Memórias.

Nem tudo entra do mesmo jeito. Algumas coisas viram sala. Outras viram nota-conceito. Outras ficam como tag. Outras só pedem um link. E às vezes eu ainda não sei o bastante para decidir. Tudo isso faz parte do sistema.

## 1. Quando algo vira sala

Eu penso em sala quando a coisa é uma região inteira da minha experiência.

Uma sala não serve para um detalhe isolado. Ela serve para um tipo de presença que volta muitas vezes e precisa de um lugar próprio. Se algo fala de emoção, pessoa, beleza, pensamento, autoconhecimento, gosto, fim, corte ou criação, eu olho primeiro para as salas.

## 2. Quando algo vira nota-conceito

Eu crio uma nota-conceito quando algo começa a aparecer várias vezes e merece existir como referência própria.

Se um tema, pessoa, objeto, lugar ou sensação cruza outras notas com frequência, eu não o deixo solto dentro de uma nota só. Eu dou a ele uma casa própria. Assim ele pode ser linkado, revisitado e expandido ao longo do tempo.

## 3. Quando algo vira tag

Eu uso tag quando quero atravessar várias notas sem prender aquilo a uma única casa.

Tag é boa para recorrências amplas, padrões menores ou marcas que atravessam salas diferentes. Ela não substitui a nota-conceito, mas ajuda a agrupar e rastrear coisas que aparecem em contextos diversos.

## 4. Quando algo vira link

Eu uso link quando uma nota precisa apontar diretamente para outra.

Link é para conexão concreta. Se uma nota fala claramente de outra, eu ligo as duas. Assim a memória não fica isolada e o sistema ganha profundidade de leitura.

## 5. Quando deixar em aberto

Eu deixo em aberto quando ainda não tenho contexto suficiente para decidir.

Se a captura é curta demais, ambígua demais ou mistura mais de uma direção com força parecida, eu não forço uma decisão artificial. Nesse caso, a nota pode esperar um pouco mais de leitura antes de ganhar forma definitiva.

## 6. Quando usar sala alternativa

Eu marco uma sala alternativa quando uma leitura principal já existe, mas há uma segunda possibilidade legítima.

Isso me ajuda a não perder a nuance. A sala principal continua sendo a escolha inicial, mas a alternativa fica registrada para revisão posterior.

## Regra prática

Se eu sinto, olho para Afetos.  
Se eu reconheço alguém, olho para o Pomar.  
Se eu vejo beleza, olho para Hator.  
Se eu penso, olho para Alexandria.  
Se eu me reconheço em padrão, olho para Maat.  
Se eu gosto ou recuso, olho para as Vozes.  
Se eu estou diante de fim ou passagem, olho para Anubis.  
Se eu estou diante de ruptura, olho para Kali.  
Se eu crio, olho para Toth.  
Se eu analiso, olho para Ganesha.

## Regra principal

Eu não preciso decidir tudo na hora.  
O sistema funciona melhor quando eu deixo a coisa chegar no lugar certo com calma.
